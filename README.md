# SDL-FP

This repository accompanies the paper **Permutation-Enhanced Supervised Dictionary Learning for Identifying Shared and Individual fMRI Activation Maps**.

## Contents

- `training.m`, `tuning.m`, and `Solve_permutation*.m` are the main experiment scripts.
- `LRSDL_FDDL/`, `ODL/`, `SRC/`, and `utils/` contain the MATLAB implementations and helpers.

## Data

Dataset are not included. Please contact us for the access.

## Note

This is a MATLAB research repository for the paper above. Start from the manuscript PDF and the top-level scripts if you want to follow the method and reproduce the experiments.
